# PageLoaderSkeleton

## Description

Centered **`OvalLoader`** (100×100) with motion scale-in; **`role="status"`**, **`aria-label="Loading"`**. Optional **`className`**.

**Source:** `src/skeletons/PageLoaderSkeleton.tsx` (props inline in file).

## Props

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| `className` | `string` | No | Wrapper classes. |

## Examples

```tsx
<PageLoaderSkeleton className="ui:min-h-dvh" />
```

## Anti-patterns

- None specific.
